# Digit Recognition using Machine Learning

## Overview
This project classifies handwritten digits using machine learning techniques and image processing.

## Features
- Data preprocessing and normalization
- Feature extraction
- Model training and evaluation
- Handwritten digit classification
- Visualization of predictions

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow/Keras

## Results
The model successfully recognizes handwritten digits with high accuracy on the test dataset.
